Add Rule Functionality Test Suite

🚀 Quick Start Test

  1. Run npm run dev to start the application
  2. Select a topic (e.g., "Business Associations")
  3. Select a subtopic (e.g., "Agency")
  4. Look for the violet "+ Add" button next to "Rules"
  5. Click it and add a test rule

📋 Manual Test Checklist

  • Add button is visible when topic and subtopic are selected
  • Add button has violet/purple color (matches Rules theme)
  • Modal opens when clicking the Add button
  • Modal shows current location (Topic > Subtopic)
  • Can enter rule name in the first field
  • Can enter rule text in the textarea
  • Validation prevents empty rule name
  • Validation prevents empty rule text
  • Validation prevents duplicate rule names
  • New rule appears immediately in the rules grid
  • New rule is automatically selected for practice
  • Rule count updates in the Rules header
  • Data persists after page reload
  • Cancel button closes modal without saving

🧪 Test Scenarios

Test 1: Basic Rule Addition

Add a simple rule with name "Test Rule" and text "This is a test rule definition."

Expected: Rule added successfully and appears in grid

Test 2: Empty Fields Validation

Try to add a rule with:

  • Empty name, filled text
  • Filled name, empty text
  • Both fields empty

Expected: Error message appears, rule not added

Test 3: Duplicate Name Validation

Try to add a rule with the same name as an existing rule

Expected: "A rule with this name already exists" error

Test 4: Special Characters

Add rules with special characters in names:

  • Rule with quotes: "Smith's Rule"
  • Rule with symbols: "Rule #1 (Important!)"
  • Rule with unicode: "Règle française"

Expected: All should work correctly

Test 5: Long Content

Add a rule with very long name and text (100+ characters each)

Expected: Should handle gracefully, possibly truncate in display
