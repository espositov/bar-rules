Subtopic Add/Delete Functionality Test

Test Instructions:

  1. Open the app by running npm run dev
  2. Select any topic from the dropdown or grid
  3. Look for the "+ Add" button next to "Subtopics" header
  4. Click the "+ Add" button to open the modal
  5. Enter a new subtopic name and click "Add Subtopic"
  6. Verify the new subtopic appears in the list
  7. Hover over any subtopic to see the delete (X) button
  8. Click the delete button to see the confirmation dialog
  9. Confirm deletion and verify the subtopic is removed

Manual Test Checklist:

  • ✓ Add button is visible when a topic is selected
  • ✓ Add modal opens when clicking the add button
  • ✓ Can enter subtopic name in the modal
  • ✓ Validation prevents empty subtopic names
  • ✓ Validation prevents duplicate subtopic names
  • ✓ New subtopic appears after adding
  • ✓ New subtopic is automatically selected
  • ✓ Delete button appears on hover
  • ✓ Delete confirmation dialog shows correct subtopic name
  • ✓ Delete confirmation shows rule count warning
  • ✓ Subtopic is removed after confirming deletion
  • ✓ If deleted subtopic was selected, another is selected
  • ✓ Data persists after page reload
